## 一、为什么要做列表页模板？

打开你的小程序，看看这些页面：

```markdown
┌─────────────────────────┐
│  好友列表                 │  ← 头像+昵称+标签
├─────────────────────────┤
│  我的关注                 │  ← 封面+标题+描述
├─────────────────────────┤
│  获赞与收藏              │  ← Tab切换+内容
├─────────────────────────┤
│  积分中心                 │  ← 头部数据+任务列表
├─────────────────────────┤
│  设置页面                 │  ← 分组+开关/箭头
├─────────────────────────┤
│  订单列表                 │  ← 商品图+状态+按钮
└─────────────────────────┘
```

**80% 的页面都是列表页**！每次都重新写，太费头发了。

于是我用 `base-card` 组合出了 **6 套模板**，覆盖最常见的列表场景。

## 二、六大类列表页卡片

### 1. 好友列表 —— friend-list

**特点**：圆角卡片 + 圆形头像 + 间距分割

```markdown
┌─────────────────────────────────────┐
│ [头像○]  产品经理                  │
│             每天进步一点点 ✨        │
│                           新朋友    │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐

│             设计改变世界              │
│                           通过微信号 │
└─────────────────────────────────────┘
```

**参数**：
- 圆角：`var(--radius-lg)` = 24rpx

## 三、统一风格：圆角 + 间距

这 6 类列表页有一个**共同的设计语言**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 圆角 | `var(--radius-lg)` | 24rpx，大圆角 |
| 间距 | `var(--space-3)` / `var(--space-4)` | 12rpx / 16rpx |
| 阴影 | `var(--shadow-sm)` | 轻微悬浮感 |

**为什么要统一？**

1. **好看**：圆角 + 间距是现代 UI 的标配
2. **高效**：一套参数组合 N 种场景
3. **好改**：想换风格？改一个变量就行

## 四、代码怎么用？

### 基础用法

```vue
<!-- 好友列表卡片 -->
<base-card
  :radius="'var(--radius-lg)'"
  :margin="'var(--space-3)'"
  :shadow="'var(--shadow-sm)'"
  clickable
>
  <!-- 你的内容 -->
</base-card>
```

### 设置列表（大卡片套小卡片）

```vue
<!-- 外层大卡片 -->
<base-card
  :radius="'var(--radius-lg)'"
  :margin="'var(--space-4)'"
  :shadow="'var(--shadow-sm)'"
>
  <!-- 内层小卡片 -->
  <base-card
    :radius="'var(--radius-none)'"
    :border="'1rpx solid var(--color-border)'"
    clickable
  >
    <!-- 设置项内容 -->
  </base-card>
</base-card>
```

### 带图片的卡片（新增！）

```vue
<base-card
  image="/avatar.png"
  image-size="80rpx"
  image-radius="var(--radius-sm)"
  :radius="'var(--radius-lg)'"
  :margin="'var(--space-3)'"
>
  <text>标题</text>
</base-card>
```

## 六、主题变量

所有模板都使用 `uniapp-theme-skill` 的主题变量：

- 圆角：`var(--radius-lg)`、`var(--radius-sm)`
- 间距：`var(--space-3)`、`var(--space-4)`
- 阴影：`var(--shadow-sm)`
- 颜色：`var(--color-primary)`、`var(--color-bg-surface)`

想换主题？改一行 CSS 变量即可！
