# uniapp 设计系统与组件规范 Skill

> uniapp 微信小程序项目的设计系统与组件开发规范

## 功能

- **Design Tokens**：四层 Token 架构、主题配置、语义变量
- **SCSS 函数与混入**：色板生成、布局/文本/安全区混入
- **组件规范**：按钮组件示例、目录结构、命名规范
- **屏幕适配**：顶部适配、底部安全区、鸿蒙降级

## 使用方式
