# 商城商品列表 · 当前局部布局

先读 uniapp-theme-skill/basic_theme.md。本文件只管商品列表，钱包、购物车、个人中心后续各自建立局部布局文件。

## 两个独立维度
- 分类入口：无中间分类 / 单行横滑分类 / 左侧树形菜单 / 搜索区域下拉面板。
- 商品排列：双栏平铺 / 横排普通列表 / 双列独立流。
- 全局主题与局部布局分别选择，不绑定某一种颜色。

## 内置五套组合
- S1 简洁平铺：搜索 + 双栏商品。无中间分类、无分类统计区，适合少量精品。
- S2 精细横滑：搜索 + 单行可左右滑动的图片分类 + 双栏商品 + 排序，适合综合商城。
- S3 树形精细：搜索 + 左侧多级菜单 + 右侧横排商品 + 排序，适合门店点单和精确分类。
- S4 下拉瀑布：搜索区全部分类入口 + 下拉分类面板 + 双列独立流。中间不重复显示分类栏，适合集市逛购。
- S5 横滑瀑布：搜索 + 单行图片分类 + 双列独立流，适合图片导向的推荐商品。

## 交互与内容细节
- JSON categories 支持单级与 children 多级，父分类覆盖后代商品；无图节点显示名称，不渲染损坏图片。
- 横滑栏只展示一级分类；多级节点在树形或下拉面板中展示，避免同一行混入所有层级。
- 卡片名称最多两行；规格/描述次级；价格突出；加购图标圆形且保留触控区，卡片采用 BaseCard。
- 只展示真实提供的字段，不伪造销量、折扣、卖家信用与配送承诺。
- 搜索、分类、排序可组合使用；底栏保留状态，遮罩覆盖H5可视区域。

## 接入
- Commerce 的 listStyle 传 S1–S5；预览路由 style=S1–S5。
- 全局颜色由 theme=coral/forest/ink 控制；不传则沿用项目当前主题。
- 旧 design=A/B/C 映射 S1/S4/S3，保留兼容；旧 layout 参数作为显式排列覆盖。
- 默认资源、组件依赖与验收要求见同目录 README.md。

## 新增可运行组合
- S6 下拉平铺：顶部分类面板 + 双栏商品；中间不重复分类栏。
- S7 横滑横排：单行图片分类 + 横排商品，适合规格信息较多的商品。
- S8 下拉横排：顶部分类面板 + 横排商品，减少头部占用。
- 共八套明确组合，由同一个 Commerce 模板实际渲染；不是八张独立设计图。所有组合可搭配 coral/forest/ink 全局主题。
