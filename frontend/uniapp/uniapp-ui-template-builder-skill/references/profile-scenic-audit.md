# 个人中心新增模板审计

日期：2026-11-16。范围：第一组 profile-gallery 五场景的构建/宽度回归，第二组 profile-scenic 五种图片场景与一种纯色圆环的源码规范、H5 行为及素材。其他历史登录页、商品页、PC 模板不在本轮运行验收范围内。

## 结论

本轮范围内未发现阻断 H5 演示运行或微信编译的问题。新增六种配置均由同一个 Vue3 模板实现，并确实调用仓库公共组件。可用于按所列场景生成和演示个人中心；接真实业务及真机仍需相应验收。

## 已修复与补齐

1. 缺少纯色风：新增 solid 配置与 solid-rings 背景模式，三层主题色静态圆形，不加载 PNG。
2. 新增网格/菜单只有 Enter 键：补充 Space 防默认滚动触发，并实测。
3. 旧 F08 要求弹层默认打开、tab 默认第一项，与个人中心真实初态冲突：改为按页面语义初始化并提供可达测试入口，不再要求强开弹层。
4. 验证证据难复跑：新增 demo/scripts/verify-scenic.py，输出机器可读 verification.json 与六张 H5 首屏。
5. 素材与部署：保留 assets/profile-scenic 为唯一真源，构建复制品忽略提交；五 PNG 较大，生产选择性部署和包体优化作为明确交付条件。

## 规范核对

- BaseCard、BaseAvatar、BaseNavbar、BaseTabbar、BaseButton、BasePopup、Empty 来自对应基础技能真源，不复制容器实现。
- 样式使用既有 theme 变量，没有定义平行 token；Hero 半透明承托层是已登记的沉浸式展示例外，业务卡片保持公共组件语义。
- 装饰层与内容层分开；圆形 pointer-events:none 且 aria-hidden；没有自建关键帧、Canvas、滤镜依赖或运行时图标库。
- mock 独立，事件由页面容器承接；没有在展示模板中自行发请求；签到为本地模拟且清理待完成定时器。
- 无字背景、提示词、视觉参考和真实运行截图均随技能提供，分别标识。
- 视觉参考图不等于逐像素实现承诺，正式运行遵循现有主题与基础组件，文章已说明差异。
