# 项目全局基础主题 · 首次建立

## 使用顺序
1. 所有页面与组件生成前先读本文件，确认项目采用的全局主题。
2. 再读当前页面的 current_theme.md 选择局部布局。局部布局不得重定义全局视觉规范。
3. 本文件定义规则，base.css 提供变量，commerce-theme.ts 保留旧商城接入配置。目录文件不自动执行代码。

## 全局配置维度
- 主题色：主色、辅助色、页面背景、卡片背景、主要/次要文字、价格与状态语义色。
- 圆角：卡片、图片、普通按钮、输入框；圆形图标操作为独立形状规范。
- 间距：页面外边距、卡片内边距、模块间距、行内间距。
- 字体与图标：沿用全局字体等级、统一线性图标，触控区至少44px。
- 作用范围：项目的商品、购物车、钱包、个人中心及后续所有页面和组件；不决定它们各自的业务布局。

## 迭代
- 修改全局参数必须同步变量与配置，并回归已交付页面；不因新增商品列表风格而改变整个项目的主题。
- 旧 commerce-design-catalog.md 仅保留历史对照；全局视觉以本文件为先，商城局部布局以 current_theme.md 为先。

## 兼容接入边界
当前可运行商城通过 data-commerce-theme 作用域消费变量，既有个人中心保持原主题机制。若应用到全项目，需在项目根容器统一绑定并验证所有页面；新增本文不会自动覆盖旧模板样式。
