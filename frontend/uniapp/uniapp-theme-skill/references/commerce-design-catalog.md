# 商城设计目录（持续迭代）

使用模板前必须读取本文件。用户指定编号则沿用；未指定时展示候选、场景与差异，请用户选择后应用。修改目录须同步运行参数和截图，文档本身不会自动修改已有项目。

## A · 品牌零售（保留并精修）
- 主色：#C2410C；辅助：#1D4ED8；背景：#FFF7ED。
- 页面边距：24rpx；卡片间距：16rpx；卡片内边距：24rpx。
- 卡片圆角：24rpx；图片圆角：16rpx；按钮圆角：16rpx；搜索胶囊。
- 模式：双栏 / 横排；适合数码品牌、精品零售。

## B · 频道逛购
- 主色：#18181B；强调：#FACC15；价格：#DC2626；背景：#F4F4F5。
- 页面边距：20rpx；列间距：16rpx；卡片内边距：20rpx。
- 卡片圆角：20rpx；图片圆角：16rpx；筛选圆角：12rpx；搜索胶囊。
- 模式：频道横栏 + 全部频道展开面板 + 双列独立流。
- 商品信息：图、两行名称、价格、商品补充信息；避免重复口号与大块空白。
- 适合二手集市、内容商品；参考结构，不复制品牌标识。

## C · 分类点单
- 主色：#15803D；辅助：#DCFCE7；价格：#DC2626；背景：#FFFFFF。
- 页面边距：20rpx；行间距：16rpx；卡片内边距：16rpx。
- 主卡圆角：16rpx；图片圆角：12rpx；分类选中圆角：8rpx；加购为圆形图标。
- 模式：搜索 + 图片分类横栏 + 全分类展开面板 + 左侧菜单 + 右侧横排商品。
- 左栏宽144rpx；商品图112rpx；右侧弹性宽；底栏预留安全区。
- 适合买菜、奶茶、门店点单；当前示例仍采用数码商品。

## 统一规则
- 搜索复用 SearchBar；弹层复用 BasePopup；导航复用 BaseTabbar；加购复用 BaseButton 的 icon。
- 同一线性图标系统，禁止汉字、emoji充当搜索或导航图标。
- 布局参数逐步迭代；未实现的业务页只登记名称，不展示虚假的成功流程。
- 参数变化需检查320/390/768宽度、分类搜索联动、弹层关闭、底栏安全区。

## 主题与页面的职责边界
- 本目录负责方案定义：语义色、间距、圆角、图标风格与商品列表布局模式。实际 CSS 数值由本技能 base.css 提供，状态与方案元数据由 commerce-theme.ts 管理。
- 页面级技能读取目录后选择方案，再引用基础组件组装；禁止把组件实现复制进主题技能。
- 布局模式是页面选择的依据，不代表主题 CSS 能自动生成业务布局。新增模式须有对应页面模板实现后才能标记可用。
- 当前 A 默认 grid，可选 editorial；B 默认 waterfall；C 默认 category。用户未指定时展示方案差异，由用户决定。
