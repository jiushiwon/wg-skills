# 商城组合主题

主题将颜色、圆角、模块间距和页面留白组合为预设，变量仍唯一存于 templates/src/static/css/base.css。commerce-theme.ts 是应用级选择状态和预设元数据；有 Pinia 的项目将选择状态合并到已有设置 store。无需业务组件重新定义变量。

应用根容器绑定 :data-commerce-theme="commerceThemeId"，让所有页面消费同一选择；原生导航/TabBar 的颜色需由应用容器订阅状态，通过对应平台 API 同步，不能认为 CSS 自动覆盖原生区域。当前演示使用页面内导航；未提供持久化、原生导航联动和真实后端。

三个预设：珊瑚优选、森林日常、都市黑标，各搭配 grid 与 editorial 两种页面布局。grid 为双栏商品与紧凑信息；editorial 为横排商品与分区阅读。布局不是 CSS Token，也不是所有页面统一两列。商品、购物车、钱包分别映射同一变体。

当前只覆盖实际消费的语义色与 500 色阶，不声称生成了三套完整 50–950 色阶。需要全色阶或其他组件色阶时先运行现有色阶生成流程并核对对比度；禁止混用新 500 与旧色阶当成已校准色板。图标沿现有统一线性资产，未增加第二套图标家族。

验收包括切换主题不清空购物车，不改变余额；3主题×2布局×3页面×窄/宽屏检查；类型、H5、微信编译分别记录。App与微信真机未验证前不承诺三端已通过。
