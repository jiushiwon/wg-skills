01

组件概览

base-dropdown 是 vue-base-skill 的 L1 业务组件，统一封装 5 种浮层形态。 所有形态共享 trigger（触发器）+ panel（浮层面板）+ 显隐逻辑， 通过 mode prop 切换行为，通过 position / trigger / tone / size 控制外观。

Event 参数 说明
update:modelValue(value: any)v-model 绑定值变化时触发

Slots 插槽表 API

Slot scope 说明
default-面板内容（覆盖默认渲染；通常用于 popover 富内容）
trigger-触发器内容（覆盖默认文本 trigger）
prefix-trigger 内的前缀图标
suffix-trigger 内的后缀图标
empty-空状态自定义内容（select 用）
loading-加载态自定义内容（select 用）
option{ option, index, selected }自定义 option 渲染（select/multi-select）
item{ item, index, disabled }自定义菜单项渲染（dropdown/mmenu）
tag{ option, index }自定义 tag 渲染（multi-select）
header-面板头部（通常放搜索框或说明）
footer-面板底部（通常放分页或确认按钮）
