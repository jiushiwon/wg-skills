# vue-radio-skill

> Vue3 单选框组件 `base-radio`，零 HTML5 标签（`<div role="radio">`）。

## 快速上手

```vue
<base-card title="支付方式">
  <base-radio v-model="pay" value="wechat">微信</base-radio>
  <base-radio v-model="pay" value="alipay">支付宝</base-radio>
</base-card>
```

## 容器原则

必须嵌入 `<base-card>` 使用。
