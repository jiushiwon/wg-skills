# vue-switch-skill

> Vue3 开关组件 `base-switch`，零 HTML5 标签（`<div role="switch">`）。

## 快速上手

```vue
<base-card title="通知设置">
  <base-switch v-model="enabled">开启消息推送</base-switch>
</base-card>
```

## 容器原则

必须嵌入 `<base-card>` 使用。
