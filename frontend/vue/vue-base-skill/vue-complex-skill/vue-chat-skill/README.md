# Vue3 Chat Skill

Vue3 高端 AI 聊天页技能，6 种差异化视觉风格。

## 快速开始

1. 复制 `templates/ChatPage.vue` 到项目
2. 导入 `tokens.css` 设计 Token
3. 设置 `variant` prop 切换风格

## 风格一览

| # | 风格 | 适用场景 | 关键词 |
|---|------|----------|--------|
| 1 | Codex 暗色终端 | 开发者工具 | codex, 终端 |
| 2 | ChatGPT 极简 | 通用 AI 对话 | minimal, chatgpt |
| 3 | 客服工单 | 客户服务 | support, 客服 |
| 4 | 消息气泡 | 社交通话 | bubble, 气泡 |
| 5 | IDE 对话 | 编程助手 | ide, vscode |
| 6 | 深色玻璃 | 高端产品 | glass, 暗黑 |
