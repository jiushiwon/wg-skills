# Vue Collapse Skill

> **容器原则**：必须嵌入 `<base-card>` 使用
> **零 HTML5 标签**：标题栏用 `<div role="button">` 模拟，不用 `<details>/<summary>/<button>`

折叠面板组件，详细规范见 [base-collapse.md](base-collapse.md)。

## 能力清单

| 能力 | 说明 |
|------|------|
| 单面板折叠 | 单个面板展开/收起 |
| 手风琴模式 | `accordion` 同时仅一项展开 |
| 禁用项 | `disabled` 面板不可展开 |
| 自定义标题 | `title` 插槽 |
