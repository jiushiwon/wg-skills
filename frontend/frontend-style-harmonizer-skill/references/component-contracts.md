# 组件契约审查规则

组件契约不是要求所有页面长得一模一样，而是规定同一语义组件在同一项目内应从同一来源、使用同一尺寸阶梯和状态集合。先比对来源，再比对视觉，最后才建议收敛。

## 证据等级

| 证据 | 置信度 | 说明 |
|---|---|---|
| 项目组件 API、Token 文件、设计规范 | 高 | 可作为已确认基线 |
| 同一公共组件被多个页面导入 | 高 | 可作为组件来源事实 |
| 模板结构 + class 名 + CSS 属性 | 中 | 仅能作为静态推断 |
| 仅 class 名或截图相似 | 低 | 必须人工确认 |

## 核心组件契约

| 组件 | 必查来源 | 必查视觉与结构 | 必查状态 |
|---|---|---|---|
| Button | 公共组件 / UI 库 / 原生 / 页面副本 | 变体、尺寸、高度、圆角、图标间距、文字层级 | hover、focus、disabled、loading、danger |
| Search | 公共搜索组件 / Input 组合 | 左侧搜索图标、placeholder、清空、筛选入口、高度、圆角 | focus、输入后、无结果、loading |
| Input / Select | 公共组件 / UI 库 / 页面副本 | label、必填、前后缀、错误文案、控件高度 | default、focus、disabled、error |
| Checkbox / Radio / Switch | 公共组件 / UI 库 / 自定义 | 选中图形、尺寸、标签间距、组内间距 | checked、unchecked、disabled、error |
| Tab | 公共组件 / 页面副本 | 高度、选中指示器、字号、间距、可滚动策略 | selected、hover、disabled |
| Card | 公共容器 / 页面副本 | 背景、边框/阴影、圆角、内边距、标题区 | default、hover、loading |
| Dialog | 公共组件 / UI 库 | 宽度、圆角、遮罩、标题、关闭入口、底部操作区 | open、closing、loading、error |
| Table / List | 公共组件 / 页面模式 | 表头、行高、分割线、操作列、分页/加载更多 | loading、empty、error、selected |
| Empty State | 公共组件 / 页面副本 | 插图、主副文案、主操作位置 | empty、permission、filtered-empty |
| Action Icon | SVG 组件 / 图标库 / 图片 / 页面私绘 | 动作图形、尺寸、颜色、点击区、标签 | default、disabled、danger、selected |

## 搜索框专项规则

1. 在同一“列表搜索”语义下，搜索图标是否存在必须由公共 Search 组件或项目规范决定；不能由页面作者随意决定。
2. 图标位置、输入高度、圆角、清空行为、筛选按钮和提交触发方式属于契约字段；有差异时逐项记录，不只写“样式不同”。
3. 全局搜索、表格搜索、移动端顶部搜索可以是三个不同契约；报告必须避免跨场景误判。
4. 若页面没有图标是明确的紧凑变体，应记录为已批准或待确认例外，而不是直接判错。

## 来源漂移判定

| 情况 | 风险 | 建议 |
|---|---|---|
| 同一语义同时使用公共组件和页面手写副本 | 高 | 优先迁移到既有公共组件，保留业务插槽 |
| 两个 UI 库混用同类控件 | 高 | 不自动替换；先确认统一库与迁移成本 |
| 同一公共组件只通过 Token 改外观 | 低 | 检查是否为受支持的 variant/size |
| 同一页面模式存在不同手写外观 | 中 | 确认是否应抽为公共变体 |

## 状态完整性

缺状态不一定都是视觉缺陷，但会导致协作页面体验割裂。审查时仅报告已存在页面可推断的状态，不能凭空断言业务必需状态。

- 交互组件：至少检查 `focus`、`disabled`、`loading` 或其等价状态。
- 表单组件：检查错误提示与禁用态是否遵循同一颜色和间距 Token。
- 列表页面：检查 `loading`、`empty`、`error` 的入口和视觉骨架是否一致。
- 图标操作：检查相同动作是否复用同一图标资产；颜色差异必须能对应 default、disabled、danger 或选中状态。
