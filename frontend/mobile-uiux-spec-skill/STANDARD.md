# 移动端 UI/UX 设计与交付规范

> 上位规范：`../AGENTS.md`；仓库规范：`../../AGENTS.md`。

## 定位

本 Skill 只定义移动端设计与交付的跨端基线，不拥有主题 Token、公共组件或安全区修复的实现权。

## 红线

1. 不把机型尺寸表当成运行时 API；状态栏、胶囊、键盘和安全区必须动态获取。
2. 不以“视觉一样”掩盖空间责任不同；页面 gutter、卡片 padding、固定区占位必须逐项说明。
3. 不把鸿蒙简单等同 Android；`vp/fp`、多窗口与折叠态单独记录。
4. 不新增平行 Token、按钮、导航、底栏或弹窗实现；必须引用现有主题和容器 Skill。
5. 不修改业务状态、接口、路由、权限或数据结构。
6. 不把静态图或模拟器结果写成真机结论；未验证项目必须明确标注待真机验证。

- [ ] 鸿蒙章节包含 `vp/fp`、窗口/折叠态与安全区，不复制 Android 规则。
