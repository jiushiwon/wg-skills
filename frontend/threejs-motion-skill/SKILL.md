# Three.js 网页动效

先问用户动作和可见反馈，再决定渲染路线。常规按钮、位移和淡入用 CSS；二维粒子或每帧重画用 Canvas 2D；空间、光照、透视和模型交互才引入 Three.js。用 WebGLRenderer 时核对目标浏览器 WebGL 2 能力。默认面向 Web，App WebView 和小程序另行验证。

1. 给效果定义触发条件、输入、开始和结束状态，以及静态替代。正文、按钮和导航留在 DOM，装饰画布不阻拦点击和滚动。
2. 最小原型只保留 Scene、Camera、Renderer 和一个 Mesh。滚动叙事用容器进度驱动相机或对象参数，先锁定起止状态，再加粒子、灯光或后期。
3. 用容器尺寸更新 renderer 和 camera，设置可调的 DPR 上限。时间动画用 delta 或时间戳，滚动只记录目标进度。避免每帧创建几何、材质和纹理。
4. 画布不可用、模型加载失败或用户偏好减少动态时，保留静态图和业务操作。页面不可见时暂停不必要的循环。
5. 在卸载时停止循环并移除观察器与监听器。释放本组件拥有的几何、材质、纹理、渲染目标和 renderer，共享资源按所有权处理。
6. 验收首屏可用、窄窗调整、滚动前后状态、无 WebGL 回退、减少动态、进出页面无重复循环。记录实测设备和未覆盖项。

交付包括选型理由、效果与状态表、可运行最小场景、静态替代方案和验收结果。需要最小起点时阅读 [示例说明](README.md)。
