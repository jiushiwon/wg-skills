# 夸大其词检测规则

## 核心原则

**AI 倾向于用绝对化语言制造"权威感"，人类更常用模糊限定词。**

AI 说"必须"、"绝对"、"一定"。人类说"可能"、"也许"、"我觉得"。

---

## 检测规则

### 1. 绝对化词汇列表

| 类别 | 词汇 | 人类替代 |
|------|------|----------|
| **绝对肯定** | 必须、绝对、一定、肯定、必然 | 可以、通常、一般、往往 |
| **绝对否定** | 完全不、绝不、从不、永不 | 很少、不太、不一定 |
| **夸大程度** | 极其、非常、特别、超级、超 | 很、挺、比较、相当 |
| **夸大效果** | 震惊、颠覆、革命性、划时代 | 有意思、有改进、有变化 |
| **夸大范围** | 所有人、每个、全部、一切 | 很多人、大多数、不少 |
| **夸大紧迫** | 必须马上、立刻、刻不容缓 | 可以考虑、建议、最好 |

### 2. 夸大句式模式

**模式一：绝对化断言**
```
AI风：这是必须掌握的技能！
人味：这个技能挺有用的。
```

**模式二：夸大效果**
```
AI风：效果震惊！立竿见影！
人味：效果还行，用了一段时间感觉有改善。
```

**模式三：夸大范围**
```
AI风：所有人都应该学会这个！
人味：我觉得大部分人可以试试。
```

**模式四：夸大紧迫**
```
AI风：现在不学就晚了！
人味：有空可以了解一下。
```

**模式五：二元对立**
```
AI风：要么学会，要么被淘汰！
人味：学不学看个人需求。
```

### 3. 人类表达特征

人类写作时通常：
- 用模糊限定词（可能、也许、大概、我觉得）
- 承认不确定性（不太确定、可能是我特殊）
- 留有余地（仅供参考、个人看法、不一定对）
- 用具体数据代替形容词（"瘦了 12 斤"而非"瘦了很多"）

---

## 检测示例

### AI 风（夸大其词）

```
这绝对是 2025 年最值得学习的技能！

所有人都必须掌握 AI，否则就会被淘汰！

这个方法效果震惊，立竿见影！

现在不学，以后一定会后悔！

这是革命性的变革，颠覆了传统行业！
```

**命中**：绝对、必须、震惊、立竿见影、革命性、颠覆、一定

### 人类风格

```
这个技能 2025 年挺火的，学学没坏处。

AI 确实在改变很多行业，但说"淘汰"可能有点夸张。

我试了一段时间，感觉有改善，但也没那么神奇。

早学晚学都行，看个人安排。

行业确实在变，但"革命性"这个词用得有点大。
```

**命中**：0 个夸大词，语气平实

---

## 修复建议

1. **删除绝对化词汇**：必须→可以、绝对→通常、一定→可能
2. **删除夸大形容词**：震惊→有意思、颠覆→改进、革命性→新
3. **加入限定词**：我觉得、可能、也许、大概、一般来说
4. **用数据代替形容词**：效果很好→用了两周，效率提升了 30%
5. **承认不确定性**：我不太确定、仅供参考、可能是我特殊
6. **避免二元对立**：要么...要么...→看情况、因人而异
