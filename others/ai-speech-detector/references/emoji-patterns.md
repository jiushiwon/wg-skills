# Emoji 滥用检测规则

## 核心原则

**零容忍：正式文章中禁止出现任何 emoji。**

无论是表格前缀、列表标识、段落装饰还是句尾点缀——全部禁止。用文字、编号或标点代替。

---

## 检测规则

### 1. 强制全文扫描

**必须逐行扫描全文，不得遗漏任何一个 emoji。**

扫描方法：
- 使用正则匹配所有 Unicode emoji 范围
- 包括但不限于：U+1F600-1F64F, U+1F300-1F5FF, U+1F680-1F6FF, U+1F900-1F9FF, U+2600-26FF, U+2700-27BF
- 表格左侧第一列、列表前缀、标题装饰——全部纳入扫描范围

### 2. 完整 Emoji 清单（需检测）

| 类别 | Emoji |
|------|-------|
| **表情** | 😊🤔💯👍😍🎉😢😡🤣😅😂 |
| **手势** | 👉👈👆👇✅❌💪👊 |
| **物品** | 📌📎🔑💡🔥⭐🌟✨🎯🚀 |
| **符号** | ⚠️🔴🟡🟢➡️⬇️⬆️⬅️ |
| **媒体** | 🎬📝📱📖🎥🖼️🎙️📊🔍 |
| **人物** | 👤👥👨👩 |
| **其他** | 💰📄🗂️📁💻🖥️ |

### 3. 判定标准

**任何 emoji 出现 = 命中**

- 1 个 emoji = 轻度问题
- 2-5 个 emoji = 中度问题
- 6 个+ emoji = 重度问题

---

## 检测示例

### 错误示范（表格前缀）

```
| 🎬 **短剧文案 Agent** | 输入题材+集数 |
| 📝 **宣传文案 Agent** | 输入产品+平台 |
```

**命中**：2 个 emoji，表格左侧第一列

### 正确示范

```
| **短剧文案 Agent** | 输入题材+集数 |
| **宣传文案 Agent** | 输入产品+平台 |
```

**命中**：0 个 emoji

---

## 修复建议

1. **删除所有 emoji**：不区分类型，全部删除
2. **表格用纯文字**：第一列不加任何装饰符号
3. **列表用编号或破折号**：不用 emoji 做前缀
4. **强调用粗体或引号**：不用 emoji 强调
5. **目录用文字标记**：用"（你在这里）"代替 📌
