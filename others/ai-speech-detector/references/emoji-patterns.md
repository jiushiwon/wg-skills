# Emoji 滥用检测规则

## 核心原则

**零容忍：正式文章中禁止出现任何 emoji。**

无论是表格前缀、列表标识、段落装饰还是句尾点缀——全部禁止。用文字、编号或标点代替。

---

## 检测规则

### 1. 强制全文扫描

**必须逐行扫描全文，不得遗漏任何一个 emoji。**

扫描时必须覆盖以下 Unicode 范围（共 17 个区间）：

| 范围 | 说明 | 示例 |
|------|------|------|
| U+1F600–U+1F64F | 表情符号 | 😊😢😡🤣 |

| U+1F680–U+1F6FF | 交通和地图符号 | 🚀🚗✈️🚢 |
| U+1F900–U+1F9FF | 补充符号和象形文字 | 🤖🧿🧸🦷 |

| U+2600–U+26FF | 杂项符号 | ☀️⭐☔⚡ |
| U+2700–U+27BF | 装饰箭头 | ➡️⬅️⬆️⬇️ |
| U+FE00–U+FE0F | 变体选择符 | 组合用 |

### 2. AI 高频 Emoji 清单（重点检测）

以下 emoji 在 AI 生成文本中出现频率最高，必须重点检测：

| 类别 | Emoji | AI 用途 |
|------|-------|---------|
| **状态标记** | ✅⚠️❌🔴🟡🟢 | 列表前缀、状态标识 |
| **强调符号** | ✨💡🔥💪🎯 | 段落开头、要点强调 |
| **箭头符号** | ➡️⬇️⬆️⬅️📌 | 流程指示、重点标记 |
| **表情符号** | 😊🤔💯👍😍 | 句尾点缀、情感表达 |
| **装饰符号** | 🌟⭐🎉🚀 | 开头结尾、成就描述 |
| **媒体符号** | 🎬📝📱📖🎥🖼️🎙️📊🔍 | 分类标识、表格装饰 |
| **人物符号** | 👤👥👨👩 | 角色标识 |
| **物品符号** | 💰📄🗂️📁💻🖥️📎🔑 | 功能标识 |

### 3. 判定标准

**任何 emoji 出现 = 命中**

- 1 个 emoji = 轻度问题
- 2-5 个 emoji = 中度问题
- 6 个+ emoji = 重度问题

## 检测示例

### 错误示范（表格前缀）

```
| 🎬 **短剧文案 Agent** | 输入题材+集数 |
| 📝 **宣传文案 Agent** | 输入产品+平台 |
```

**命中**：2 个 emoji，表格左侧第一列

### 正确示范

```
| **短剧文案 Agent** | 输入题材+集数 |
| **宣传文案 Agent** | 输入产品+平台 |
```

**命中**：0 个 emoji

---

## 修复建议

1. **删除所有 emoji**：不区分类型，全部删除
2. **表格用纯文字**：第一列不加任何装饰符号
3. **列表用编号或破折号**：不用 emoji 做前缀
4. **强调用粗体或引号**：不用 emoji 强调
5. **目录用文字标记**：用"（你在这里）"代替 📌
