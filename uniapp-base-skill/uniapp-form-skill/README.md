# uniapp-form-skill

> uni-app 表单组件技能。

## 核心组件

- **base-input** - 输入框组件
- **base-switch** - 开关组件
- **base-radio** - 单选组件
- **base-select** - 下拉选择组件

## 功能

- 输入框（8 种通用 + 6 种搜索栏）
- 开关（6 种风格）
- 单选（6 种风格）
- 下拉选择（6 种风格）

> 弹窗组件 (base-popup) 已移至 uniapp-page-skill（页面性质）

## 使用方式

```markdown
/uniapp-form-skill 做一个输入框
/uniapp-form-skill 做一个胶囊开关
/uniapp-form-skill 做一个单选
/uniapp-form-skill 做一个下拉选择
```
