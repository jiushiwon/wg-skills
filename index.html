技能协作全景

项目初始化 → 规范驱动开发 → 审计与治理 → 升级与维护

每个阶段有专门的技能负责执行、规范和审查，阶段之间通过共享规范文件（api-contract.md、Design Tokens、component-commands）串联。

1

项目启动 — 从零到一的脚手架

快速搭建标准化 uniapp 项目骨架，或从零生成 UI 页面。解决「新建项目不知道该做什么」的问题。

📱

uniapp-app-generate-skill

从零生成标准化 uni-app 项目（微信小程序/H5/App 三端），Vue3 + TS + Pinia + SCSS，内置主题色阶与跨平台抽象层。

帮我做一个 uniapp 小程序 初始化 uniapp 项目
🧱

ui-template-builder-skill

37 套预置页面模板（个人中心/商品详情/登录页/数据大屏等），5 套风格可选，内置 Mock 数据，一键换肤。

做个个人中心页面 生成商品详情页
🎨

frontend-ui-foundry

综合性前端 UI 技能：8 大场景、6 大技术栈、品牌套用、Design Token 提取。forge / optimize / audit 等 8 子命令。

用 foundry 做一个落地页 /frontend-ui-foundry
2

开发编码 — 规范驱动的高效编写

通过开发规范、设计系统、主题系统、请求层封装和组件指令，确保团队编写风格统一的代码。

📐

uniapp-standard-skill

20 条红线规则、目录结构、接口封装、状态管理、路由规范、组件通信、埋点等 8 份详细规范文档。

/uniapp-standard 接口怎么写
🎯

uniapp-style-skill

Design Tokens 四层架构、排版/间距/语义变量、SCSS 函数、10+ 组件规范、深色模式与屏幕适配。支持设计审计与自动修复。

/uniapp-design 设计审计
🖌️

uniapp-theme-skill

动态色阶生成（任意 HEX 输入）、7 种预设主题、三维度一键切换换肤，强制统一硬编码颜色。

/uniapp-theme 添加主题系统，主色 #2563EB
📡

uniapp-request-skill

统一 request.ts 封装：鉴权拦截自动注入 Token、401 刷新重试、并发去重、防抖、Mock、SSE 流式请求。

/uniapp-request request.ts 怎么写
🔐

uniapp-components-skill

登录鉴权与安全规范：认证服务架构、Token 管理、401/403 并发去重、登出回跳、接口/数据/代码安全。

/uniapp-components 登录鉴权怎么做
🧱

uniapp-page-components-skill

常用组件化页面技能：15 个组件（空卡片/按钮/头部导航/底部菜单/表单行 + 列表/聊天/朋友圈/详情/我的/图片卡/搜索/表单/登录/首页）。BaseCard 托底，slot 自由填充，主题自动检测对齐 + 替换 tabBar/导航栏。

/uniapp-page-components 帮我做个聊天页 订单列表页 朋友圈 / 我的页面 登录页 / 搜索页 卡片圆角调整 自定义按钮 / 底部菜单
🎯

ui-component-commands-skill

预定义指令 + CSS 变量绑定，一句话生成精确样式组件。btn-primary / solid-line / icon-tag / badge 等。

做一个主按钮 加个分割线
🖼️

ui-replica-skill

原型图 → 结构化分析 → Token 收敛 → 代码生成。专门复刻 AI UI 生成器的截图（v0/Stitch/Galileo 等）。

/ui-replica-skill 复刻这张图
3

质量保障 — 上线前的全面体检

代码审计、跨平台兼容检查、样式一致性治理，确保项目在安全、性能、合规上达到生产标准。

🔍

uniapp-code-audit-skill

10 维度全面体检：安全合规、性能、代码质量、架构、UI/主题一致性、跨平台、小程序专项、App 端专项、冗余死代码、三端差异。P0-P3 分级，报告 only。

/uniapp-code-audit-skill 审计 uniapp 代码
🌐

uniapp-crossplatform-audit-skill

审计 H5/小程序/App 三端差异：模板标签检查、CSS 兼容性、API 调用差异，按文件维度输出修复指南。

/uniapp-crossplatform-audit-skill 审计多端兼容性
🩺

frontend-code-doctor

前端代码审查：类型安全、uniapp 特有规范、Vue3/React 最佳实践、性能、安全、i18n、无障碍 7 维度。

/frontend-code-review 审查下这个前端项目
🎯

frontend-style-harmonizer-skill

跨页面样式重复检测、同类组件尺寸对齐、硬编码裸值变量化。报告模式 + 自动落地，uniapp 优先。

统一各页面样式 去硬编码
4

维护升级 — 存量项目的持续演进

项目规范化诊断与 Vue2→Vue3 迁移，帮助存量项目保持健康、跟上技术栈迭代。

📐

uniapp-standardization-skill

对比现有项目 vs 标准骨架，出具规范化诊断报告和按优先级排序的重构计划。涵盖目录结构、API 层、状态管理、组件规范。

/uniapp-standardization-skill 项目规范化
⬆️

uniapp-vue2-upgrade-skill

Vue2→Vue3+TS+Pinia 迁移：现状扫描、依赖兼容评估、语法对照、脚手架升级、按优先级分步代码迁移。

/uniapp-vue2-upgrade-skill vue2 升级 vue3
