# Spring Boot Dict Module Skill

字典/配置模块技能，面向已有 Spring Boot 项目，快速集成系统参数、字典数据、配置管理能力。

## 功能

快速集成字典管理、系统配置、枚举值管理、参数配置等能力。

## 使用方式

```
帮我加字典模块
集成配置管理
加个系统参数
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 字典管理 | 字典类型、字典项 CRUD |
| 系统配置 | 系统参数配置 |
| 枚举映射 | 前端下拉/单选的数据源 |
| 缓存支持 | 字典数据缓存 |
