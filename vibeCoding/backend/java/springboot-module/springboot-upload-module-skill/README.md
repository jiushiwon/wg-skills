# Spring Boot Upload Module Skill

文件上传模块技能，面向已有 Spring Boot 项目，快速集成文件上传、图片处理、OSS 存储等能力。

## 功能

快速集成文件上传、本地/OSS 存储、图片处理、附件管理等能力。

## 使用方式

```
帮我加文件上传
集成 OSS
加个附件管理
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 文件上传 | 单文件/多文件上传 |
| 本地存储 | 本地文件存储 |
| OSS 存储 | 阿里云/腾讯云 OSS |
| 图片处理 | 缩略图/水印 |
