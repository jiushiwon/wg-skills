# 支付宝商户开通与配置完整指南

> 本文档由 springboot-alipay-pay-skill 提供，**从"0 商户号"到"成功下单"全流程**。

## 0. 流程总览

```
[步骤 1] 注册支付宝开放平台账号              ← 立即可用
[步骤 2] 实名认证（企业/个体）              ← 1-3 工作日
[步骤 3] 创建应用（网页/移动/小程序）        ← 立即可用
[步骤 4] 生成密钥对 + 上传应用公钥           ← 关键步骤
[步骤 5] 配置支付宝公钥                     ← 关键步骤
[步骤 6] 应用上线（提交审核）                ← 1-7 工作日
[步骤 7] 配置回调地址                       ← 立即可用
[步骤 8] 沙箱测试 → 正式上线
```

---

## 步骤 1：注册开放平台账号

**入口**：https://open.alipay.com/

- 已有支付宝账号 → 直接登录
- 没有 → 注册（用邮箱或手机号）

---

## 步骤 2：实名认证

### 2.1 入口

开放平台 → 「账号中心」→ 「实名认证」

### 2.2 主体类型

| 类型 | 需要资料 |
|------|----------|
| **企业** | 营业执照、法人身份证、对公账户 |
| **个体工商户** | 营业执照、法人身份证、结算银行卡 |
| **个人开发者**（受限） | 身份证（**不能用于生产**） |

### 2.3 时长

**1-3 个工作日**。审核通过后能创建应用。

---

## 步骤 3：创建应用

### 3.1 应用类型

| 应用类型 | 适用支付场景 | 推荐度 |
|----------|--------------|--------|
| **网页/移动应用** | 当面付 / WAP / PC / App | ⭐⭐⭐⭐⭐ |
| **小程序** | 支付宝小程序 | ⭐⭐⭐⭐ |
| **生活号** | 服务窗 | 旧版，**不推荐** |

### 3.2 创建步骤

1. 开放平台 → 「控制台」→ 「创建应用」
2. 选择「网页/移动应用」→ 填写应用名称 + 简介
3. 勾选需要的「应用能力」：
   - ✅ **当面付**（线下收银）
   - ✅ **手机网站支付**（H5）
   - ✅ **电脑网站支付**（PC）
   - ✅ **APP 支付**（移动 App）
4. 提交 → 进入「开发中」状态

## 步骤 4：生成密钥对 + 上传应用公钥

### 4.1 密钥对概念

支付宝使用 **RSA2（非对称加密）**：

| 密钥 | 谁持有 | 作用 |
|------|--------|------|
| **应用私钥** | 商户自己 | 签名（**绝不能泄露**） |
| **应用公钥** | 商户自己 | 上传给支付宝 |
| **支付宝公钥** | 支付宝 | 商户验签用 |

### 4.2 生成密钥对（推荐 3 种方式）

**方式 1：支付宝开放平台助手（推荐）**
- 下载：https://opendocs.alipay.com/common/02kkv7
- macOS / Windows 都有，一键生成 PKCS8 格式

**方式 2：OpenSSL 命令**
```bash
# 生成 2048 位 RSA 私钥
openssl genrsa -out app_private_key.pem 2048

# 提取公钥
openssl rsa -in app_private_key.pem -pubout -out app_public_key.pem

# 私钥转 PKCS8 格式（Java 必须）
openssl pkcs8 -topk8 -nocrypt -inform PEM -in app_private_key.pem -outform PEM -out app_private_key_pkcs8.pem
```

**方式 3：在线工具**
- https://miniu.alipay.com/keytool/create

### 4.3 上传应用公钥

1. 开放平台 → 「控制台」→ 选择应用 → 「应用信息」→ 「接口加签方式」
2. 选择「公钥」模式
3. 把 `app_public_key.pem` 的内容粘贴到文本框
4. 保存 → 系统会显示**支付宝公钥**（复制下来！）

### 4.4 关键文件清单

| 文件 | 配置项 | 备注 |
|------|--------|------|
| 应用私钥（PKCS8） | `alipay.private-key` | 整段 PEM 含 BEGIN/END 头 |
| 支付宝公钥 | `alipay.alipay-public-key` | 整段 PEM 含 BEGIN/END 头 |
| APPID | `alipay.app-id` | 16 位数字 |

**特别注意**：
- ✅ 配的是**支付宝公钥**（不是应用公钥！）—— 90% 新人栽在这里
- ✅ 私钥必须 PKCS8 格式（Java 要求）
- ✅ **不要**去掉 BEGIN/END 头

## 步骤 5：应用上线

### 5.1 提交审核

应用默认「开发中」状态，**只能沙箱测试**。要上线必须提交审核。

1. 开放平台 → 「控制台」→ 选择应用
2. 填写应用基本信息（应用名称、图标、应用描述、官网 URL）
3. 提交「应用上线」申请
4. 等待审核（**1-7 个工作日**）

### 5.2 审核常见拒绝原因

| 原因 | 解决 |
|------|------|
| 网站无法访问 | 必须有正式域名 + ICP 备案 + 网站内容 |
| 应用类目不对 | 选正确类目（电商/生活服务/教育等） |
| 资料不全 | 补充营业执照 + ICP 备案截图 |

## 步骤 6：配置回调地址

### 6.1 回调地址要求

| 要求 | 说明 |
|------|------|
| **公网可访问** | 支付宝服务器必须能 POST 到你的回调地址 |
| **HTTP/HTTPS 均可** | 支付宝支持 HTTP（生产建议 HTTPS） |
| **POST 方法** | 微信用 POST 发送回调 |
| **返回 success** | 业务处理后必须返回纯文本 "success"（小写，无空格） |

### 6.2 回调地址示例

```
生产：https://pay.yourdomain.com/api/alipay/notify
测试：https://test-pay.yourdomain.com/api/alipay/notify
```

> **微信必须 HTTPS，支付宝 HTTP 即可** —— 这是两者重要区别。

### 6.3 内网穿透（开发阶段）

同微信支付章节（frp / ngrok / cpolar 通用）。

## 步骤 7：沙箱测试

### 7.1 什么是沙箱？

支付宝沙箱提供**完整测试环境**：
- 沙箱 appid：`2021000000000000`
- 沙箱网关：`https://openapi.alipaydev.com/gateway.do`
- 沙箱买家账号：登录沙箱后自动生成（带余额 99999 元）
- 沙箱卖家账号：登录沙箱后自动生成

### 7.2 沙箱配置

```yaml
alipay:
  app-id: 2021000000000000
  private-key: 沙箱应用私钥
  alipay-public-key: 沙箱支付宝公钥
  gateway-url: https://openapi.alipaydev.com/gateway.do
```

### 7.3 沙箱测试账号获取

1. 开放平台 → 「沙箱」→ 登录（用主账号）
2. 系统显示「买家账号」和「卖家账号」
3. 用「买家账号」登录「沙箱支付宝 App」（**只能用沙箱 App**）进行扫码支付测试

### 7.4 沙箱测试要点

| 场景 | 沙箱支持 |
|------|----------|
| 当面付（扫码） | ✅ 完整流程 |
| 手机网站支付 | ✅ |
| PC 网站支付 | ✅ |
| App 支付 | ⚠️ 需真机（沙箱 App） |
| 退款 | ✅ |
| 回调通知 | ✅（通过沙箱网关通知） |

## 常见问题 FAQ

### Q1: 回调验签一直失败

**原因**：
1. 用错了公钥（**应用公钥** 而不是**支付宝公钥**）
2. 私钥不是 PKCS8 格式
3. sign_type 不匹配（公钥模式必须用 RSA2）

**排查**：
```bash
# 验证私钥 PKCS8 格式
head -1 app_private_key_pkcs8.pem
# 应输出：-----BEGIN PRIVATE KEY-----

# 验证公钥格式
head -1 alipay_public_key.pem
# 应输出：-----BEGIN PUBLIC KEY-----
```

### Q2: 沙箱支付成功但回调收不到

**原因**：沙箱回调地址必须**公网可访问**，内网不行。

**解决**：用 frp 内网穿透到沙箱回调地址。

### Q3: 报 "ACQ.PAYMENT_FAIL"

**原因**：
1. 余额不足（沙箱账号余额 < 支付金额）
2. 买家账号状态异常
3. 风控拦截

### Q4: WAP 支付跳到登录页

**原因**：用了沙箱 appid 但配生产网关，或反过来。

**解决**：appid 网关必须匹配（沙箱-沙箱，生产-生产）。

### Q5: 个人开发者能申请吗？

**能申请**，但：
- ❌ 不能用于生产
- ❌ 不能签约支付产品
- ❌ 只能沙箱测试
- ✅ 适合开发学习

**生产必须**：企业 / 个体工商户 / 小微商户。
