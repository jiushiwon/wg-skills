# Java Notification Module Skill

面向已有 Spring Boot 项目的通知模块快速集成技能。

## 功能

快速集成短信、邮件、站内消息、推送通知等能力。

## 使用方式

```
帮我加短信
集成通知模块
```

## 能力

| 能力 | 说明 |
|------|------|
| 短信发送 | 验证码/通知 |
| 邮件推送 | HTML/文本邮件 |
| 站内消息 | 系统通知 |
| 推送通知 | 极光/信鸽 |
