# Go Gin Storage Module Skill

静态资源库模块技能，面向已有 Go Gin 项目，快速集成文件上传、下载、预览、大文件分片上传等能力。

## 功能

快速集成静态资源管理能力，支持小文件直接上传、大文件切割上传、文件压缩、断点续传、存储策略切换。

## 使用方式

```
帮我加静态资源模块
Go 文件上传模块
Gin 文件上传
大文件上传模块
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 小文件上传 | 单文件/多文件直接上传（< 10MB） |
| 大文件切割上传 | 分片上传 + 断点续传（≥ 10MB） |
| 文件压缩 | 可选开启，支持图片压缩 |
| 文件下载 | 流式下载、断点续传下载 |
| 文件预览 | 图片/视频/文档在线预览 |
| 存储策略 | 本地 / 阿里云 OSS / 腾讯云 COS / MinIO |
