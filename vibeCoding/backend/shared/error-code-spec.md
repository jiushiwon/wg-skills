# 全局错误码规范（单一事实来源）

> **本文件是所有后端技能和前端请求层错误码的唯一事实来源。**
>
> - 后端 init-skill / module-skill：**禁止内联错误码表**，必须引用本文件
> - 前端 `frontend-request-skill`：`ERROR_CODE_MAP` 必须与本文件对齐
> - 新增错误码只能追加，**不得修改已有错误码的含义**

## 错误码表

| code | 含义 | HTTP 状态码 | 触发场景 |
|------|------|------------|---------|
| `0` | 成功 | 200 | 业务正常 |
| `-1001` | 参数校验失败 | 400 | 必填字段缺失、格式错误、Pydantic/JSR303 校验失败 |
| `-1002` | 未授权 | 401 | Token 缺失、无效或过期、用户名或密码错误 |
| `-1003` | 禁止访问 | 403 | 权限不足（预留，当前 auth-module 未实现 RBAC 时可复用 -1002） |
| `-1004` | 资源不存在 | 404 | 用户/数据/记录未找到 |
| `-1005` | 资源冲突 | 409 | 用户名已存在、旧密码错误、重复提交、唯一约束冲突 |
| `-1006` | 请求过于频繁 | 429 | 限流触发（预留） |
| `-1031` | 请求体过大 | 413 | 上传文件超过 `UPLOAD_MAX_SIZE` |
| `-1032` | 不支持的文件类型 | 415 | 上传文件 MIME 不在白名单 |
| `-2000` | 系统异常 | 500 | 未捕获异常、未知错误 |
| `-2001` | 数据库异常 | 500 | 数据库连接失败、查询超时（禁止暴露 SQL 细节） |
| `-2002` | 第三方服务异常 | 502 | 外部 API 调用失败、支付网关异常 |

## 错误码分段

| 段 | 范围 | 用途 |
|----|------|------|
| 业务错误 | `-1001` ~ `-1099` | 参数校验、鉴权、资源操作 |
| 上传错误 | `-1031` ~ `-1039` | 文件上传相关 |
| 系统错误 | `-2000` ~ `-2099` | 内部异常、第三方服务 |
| 模块扩展 | `-3001` ~ `-3999` | 各 module-skill 自定义（如支付模块 -3001 支付失败） |

## 模块扩展示例

各 module-skill 可在 `api-contract-<module>.md` 中扩展错误码，**必须使用 `-3xxx` 段**：

| module | code | 含义 |
|--------|------|------|
| payment | `-3001` | 支付创建失败 |
| payment | `-3002` | 支付回调签名无效 |
| notification | `-3001` | 短信发送失败 |
| storage | `-3001` | 存储服务不可用 |

## 前端 ERROR_CODE_MAP 对齐

前端 `src/config/error.config.ts` 必须包含以下映射：

```typescript
export const ERROR_CODE_MAP: Record<string, string> = {
  // HTTP 状态异常（请求层字符串码）
  UNAUTHORIZED: '登录已过期，请重新登录',
  FORBIDDEN: '权限不足',
  TIMEOUT: '请求超时，请检查网络',
  NETWORK_ERROR: '网络异常，请稍后重试',

  // 业务异常（与本文件 error-code-spec.md 对齐）
  '-1001': '参数校验错误',
  '-1002': '未登录或 Token 无效',
  '-1003': '无权限',
  '-1004': '资源不存在',
  '-1005': '资源冲突',
  '-1006': '请求过于频繁',
  '-1031': '文件过大',
  '-1032': '不支持的文件类型',
  '-2000': '系统繁忙，请稍后再试',
};
```
