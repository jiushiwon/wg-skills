# 上线前自查清单

按场景勾选，不适用的跳过。

## 通用

- [ ] 没有硬编码密钥（搜一遍 `secret`、`password`、`key` 字面量）
- [ ] `.env` 在 `.gitignore` 里，`.env.example` 只有键名没有值
- [ ] 启动时校验密钥长度，不达标直接退出而不是打条警告继续跑
- [ ] 依赖已写进依赖清单，没有手写实现
- [ ] 日志已脱敏，CI 日志里不会出现完整密钥/密码/身份证/银行卡
- [ ] 随机值来自安全随机源

## 用户密码

- [ ] 用 bcrypt（cost 12）或 Argon2id，不是裸哈希
- [ ] 校验走库的哈希串（自带盐），不是自己拿密码算一遍比固定值
- [ ] 有重哈希升级路径（参数变更后登录时自动重算）
- [ ] 登录失败提示不区分"用户不存在"和"密码错误"
- [ ] 有登录频率限制 / 锁定

## 支付与回调

- [ ] 验签在第一行，验签失败不落库不发货
- [ ] 验签用常量时间比较
- [ ] 回调幂等（按交易号去重）
- [ ] 平台证书 / 支付宝公钥支持更新（多证书并存）
- [ ] 敏感字段解密用 APIv3 密钥，AAD 正确

## JWT

- [ ] 固定期望算法，不读 header 的 alg
- [ ] 密钥 ≥32 字节且来自环境变量
- [ ] 校验 exp / nbf / iss / aud
- [ ] 有 Access / Refresh 双令牌，Refresh 可撤销
- [ ] 登出后旧令牌立即失效（黑名单 / 短有效期）

## 数据落库

- [ ] 敏感字段是密文（AES-256-GCM）且带 AAD 绑字段
- [ ] 数据库里搜不到明文敏感数据
- [ ] 密钥与数据不在同一个存储里（应用层加密的意义所在）

## 传输

- [ ] 全站 HTTPS，中间无降级
- [ ] 只留 TLS 1.2/1.3，禁用 1.0/1.1
- [ ] 证书自动续期（Let's Encrypt / 云厂商托管）
- [ ] 内部敏感服务用 mTLS 或服务间签名

## 供应链

- [ ] 仓库接了密钥扫描（gitleaks / trufflehog），历史提交也扫过
- [ ] 依赖有锁文件
- [ ] 密钥一旦泄露，已轮换而非只删除
