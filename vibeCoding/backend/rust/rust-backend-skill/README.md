# rust-backend-skill

> 面向零基础开发者，一键生成 Rust + Axum Web 后端骨架。

## 快速上手

```
帮我用 Rust 搭一个后端
初始化一个 Axum 项目
```

技能按「环境检测 → 项目生成 → 数据库集成 → JWT 鉴权 → 热重载」流程执行。

## 覆盖能力

- 环境检测（Rust / Cargo 版本）
- Axum + Tower 项目骨架生成
- SQLx + MySQL / PostgreSQL 集成
- JWT 鉴权（jsonwebtoken）
- cargo-watch 热重载
- 统一响应信封 `{ code, message, data }`
