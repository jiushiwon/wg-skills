# MongoDB Module Skill

面向已有后端项目的 MongoDB 快速集成技能。

## 功能

快速集成 MongoDB 连接、文档模型、CRUD 操作、聚合查询等能力。

## 使用方式

```
帮我加 MongoDB
集成 MongoDB 数据库
```

## 能力

| 能力 | 说明 |
|------|------|
| 连接配置 | MongoClient/连接池 |
| 文档模型 | Document/Entity 设计 |
| CRUD 操作 | 增删改查 |
| 聚合查询 | Match/Group/Lookup |
| 索引优化 | 索引设计 |
| 事务处理 | 多文档事务 |
