# PostgreSQL Module Skill

面向已有后端项目的 PostgreSQL 快速集成技能。

## 功能

快速集成 PostgreSQL 连接、表结构设计、ORM 映射、JSON/数组支持等能力。

## 使用方式

```
帮我加 PostgreSQL
集成 PostgreSQL 数据库
```

## 能力

| 能力 | 说明 |
|------|------|
| 连接配置 | JDBC/连接池/GORM |
| 表结构设计 | DDL 建表 |
| ORM 映射 | 实体类/Repository |
| JSON/JSONB | JSON 文档存储 |
| 数组类型 | PostgreSQL 原生数组 |
| 索引优化 | GIN/GiST 索引 |
| 事务处理 | 声明式/编程式 |

## 语言支持

| 语言 | 框架 | 说明 |
|------|------|------|
| Java | Spring Boot | JDBC + HikariCP |
| Python | FastAPI | SQLAlchemy + psycopg2 |
| Go | Gin | GORM |
