# MySQL Module Skill

面向已有后端项目的 MySQL 快速集成技能。

## 功能

快速集成 MySQL 连接、表结构设计、ORM 映射、索引优化、事务处理等能力。

## 使用方式

```
帮我加 MySQL
集成 MySQL 数据库
```

## 能力

| 能力 | 说明 |
|------|------|
| 连接配置 | JDBC/连接池/GORM |
| 表结构设计 | DDL 建表 |
| ORM 映射 | 实体类/Repository |
| 索引优化 | 索引设计 |
| 事务处理 | 声明式/编程式 |
| 主从复制 | 读写分离 |

## 语言支持

| 语言 | 框架 | 说明 |
|------|------|------|
| Java | Spring Boot | JDBC + HikariCP |
| Python | FastAPI | SQLAlchemy + PyMySQL |
| Go | Gin | GORM |
