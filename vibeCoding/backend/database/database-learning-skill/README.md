# database-learning-skill

数据库学习与选型技能。面向零基础学习者，系统学习数据结构、事务、索引、查询优化等核心概念，对比 MySQL 与 PostgreSQL 的差异与适用场景。

## 学习模块

- 数据结构与表设计
- SQL 查询基础
- 索引原理与实战
- 事务与并发控制
- 查询优化技巧
- MySQL vs PostgreSQL 选型
