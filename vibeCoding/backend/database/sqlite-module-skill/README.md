# SQLite Module Skill

SQLite 嵌入式数据库模块技能，面向已有后端项目，快速集成轻量级数据库能力。

## 功能

快速集成 SQLite 连接配置、CRUD 操作、事务处理、并发访问等能力。

## 使用方式

```
帮我加 SQLite
集成轻量数据库
嵌入式数据库
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 连接配置 | SQLite 文件路径配置 |
| CRUD 操作 | 增删改查 |
| 事务处理 | 提交/回滚 |
| 并发访问 | WAL 模式优化 |

## 语言支持

| 语言 | 框架 | 说明 |
|------|------|------|
| Java | Spring Boot | JDBC SQLite |
| Python | FastAPI | sqlite3 标准库 |
| Go | Gin | database/sql + go-sqlite3 |
