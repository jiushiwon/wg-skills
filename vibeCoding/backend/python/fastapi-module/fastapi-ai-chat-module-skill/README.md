# FastAPI AI Chat Module Skill

面向已有 FastAPI 项目的 AI 聊天模块快速集成技能。

## 功能

快速集成 AI 对话、会话管理、流式输出等能力。

## 使用方式

```
帮我加 AI 聊天
集成 AI 对话模块
```

## 能力

| 能力 | 说明 |
|------|------|
| 会话管理 | 创建/查询/删除会话 |
| 消息管理 | 发送/接收消息 |
| 上下文记忆 | 会话上下文保存 |
| 流式输出 | SSE 流式响应 |
| Token 统计 | 消耗统计 |
