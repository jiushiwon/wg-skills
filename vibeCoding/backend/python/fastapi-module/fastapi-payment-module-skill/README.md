# FastAPI Payment Module Skill

面向已有 FastAPI 项目的支付模块快速集成技能。

## 功能

快速集成微信支付、支付宝支付、退款、回调通知等能力。

## 使用方式

```
帮我加支付
集成微信/支付宝
```

## 能力

| 能力 | 说明 |
|------|------|
| 微信支付 | JSAPI/小程序/H5/App |
| 支付宝支付 | wap/PC/App |
| 退款 | 退款申请/查询 |
| 回调通知 | 异步通知验签 |
| 对账 | 账单核对 |
