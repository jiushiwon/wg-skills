# FastAPI Org Permission Module Skill

面向已有 FastAPI 项目的组织权限模块快速集成技能。

## 功能

快速集成组织架构、部门管理、角色权限、RBAC、菜单管理等能力。

## 使用方式

```
帮我加权限
集成 RBAC
```

## 能力

| 能力 | 说明 |
|------|------|
| 组织架构 | 组织/部门管理 |
| 用户管理 | 用户-部门-岗位 |
| 角色管理 | 角色与权限 |
| 菜单管理 | 前后端菜单 |
| 权限控制 | 按钮/接口级 |
| 数据权限 | 行级隔离 |
