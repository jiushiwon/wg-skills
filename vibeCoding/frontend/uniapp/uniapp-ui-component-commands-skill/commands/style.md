# 样式类组件（style）

> 实现真源：`vibeCoding/frontend/uniapp/uniapp-base-skill/`
> 本文件由 `components/_registry.json` + 各组件 `props.json` 同步生成，**改实现必须重新生成本文件**。
> 重新生成：`node scripts/gen-commands.js`

## 总览

| 组件 | 说明 | 别名 | 类型 |
|------|------|------|------|
| `btn` | 按钮 CSS 类 | 按钮样式类 / btn-style / ui-btn / 主按钮样式 | 样式类 |
| `card` | 卡片 CSS 类 | 卡片样式类 / card-style / ui-card / 面板样式 | 样式类 |
| `combo` | 组合类 CSS 类 | 组合 / combo / 图文组合 / 徽标组合 | 样式类 |
| `line` | 线条 CSS 类 | 分割线 / line / 横线 / 虚线 | 样式类 |
| `shape` | 图形 CSS 类 | 图形 / shape / 圆形 / 标签角标 | 样式类 |

## btn 按钮样式类

**说明**：按钮 CSS 类

**别名**：按钮样式类、btn-style、ui-btn、主按钮样式

**路径**：`vibeCoding/frontend/uniapp/uniapp-base-skill/styles/button/`

**CSS 类**：

| 类名 | 说明 |
|------|------|
| `btn-primary` | 主按钮 - 主要操作 |
| `btn-secondary` | 次按钮 - 次要操作 |
| `btn-ghost` | 幽灵按钮 - 边框样式 |

| `btn--small` | 小号按钮 |
| `btn--large` | 大号按钮 |
| `btn--block` | 块级按钮 - 宽度100% |

**用法**：见 [usage.md](../../uniapp-base-skill/styles/button/usage.md)
