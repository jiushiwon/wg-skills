# uniapp-page-skill

> uni-app 页面模板技能。

## 核心案例

- **chat** - 聊天页面
- **product** - 商品页面

## 功能

- 列表页（6 种）
- 详情页（6 种）
- 搜索页（4 种）
- 登录页（7 种）
- 自定义 TabBar（5 种）

## 使用方式

```markdown
/uniapp-page-skill 做一个聊天页面
/uniapp-page-skill 做一个商品详情页
/uniapp-page-skill 做一个好友列表
/uniapp-page-skill 做一个登录页
```

## 目录说明

```
├── chat.md               # 聊天页案例
├── product.md           # 商品页案例
└── demo-components/
    ├── list/           # 列表页案例集
    ├── detail/         # 详情页案例集
    ├── layout/         # 登录页、TabBar
    └── more/           # 更多页面
```
