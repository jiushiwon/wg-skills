# mobile-safe-area-audit-skill 个体规范

> 上位规范：`vibeCoding/frontend/AGENTS.md`；仓库规范：根 `AGENTS.md`。

## 定位

本 Skill 只处理移动端可视区责任与适配审计，不承担普通组件美化或业务功能改造。

## 约束

1. 默认只读，先报告后修复。
2. 不把静态证据写成真实设备结论。
3. 不新建与项目既有 mixin / composable 并行的安全区方案。
4. 任何修复都要同时核对顶部、底部、固定区、键盘与最后一项可达性。
5. 原生导航、自绘导航、沉浸式页面必须分 Variant 报告。

## 自检清单

- [ ] 已找到项目的导航与安全区真源，或明确标为缺失。
- [ ] 每个 P1 / P2 都有文件位置、证据、责任方和验证动作。
- [ ] fixed/sticky 均已反查内容预留。
- [ ] 键盘结论没有越过真机验证边界。
- [ ] `--apply` 仅改变已确认的视觉层实现。
