# base-form Demo 组件

> Vue 表单体系组件演示。每个 HTML 文件可独立运行。

## 文件列表

| 文件 | 说明 |
|------|------|
| `00-showcase.html` | 总览：所有表单组件 |
| `01-basic.html` | 基础表单 |
| `02-validation.html` | 表单校验 |
| `03-layout.html` | 表单布局 |
| `04-input.html` | 输入框 |
| `05-select.html` | 选择器 |
| `06-checkbox.html` | 复选框 |
| `07-radio.html` | 单选框 |
| `08-switch.html` | 开关 |
| `09-datepicker.html` | 日期选择器 |

## 运行方式

```bash
# 直接用浏览器打开
start demo-components/base-form/html/00-showcase.html

# 或用 live-server
npx live-server demo-components/base-form/html/
```

## 依赖

- **vue@3**：Composition API
- **零第三方组件库**：纯 CSS 实现
- **tokens.css + demo.css**：公共样式
