# AI 创作工作台验收清单

## 组件复用

- [ ] 输入意图使用 `base-input`，没有自定义输入框。
- [ ] 生成、保存、重新生成等操作使用 `base-button`。
- [ ] 画布、参数和结果容器使用 `base-card`。
- [ ] 参数选择使用 `base-dropdown`，状态和风格使用 `base-tag`。
- [ ] 新建草稿与破坏性操作通过 `base-dialog` 或 `base-confirm`。

## Demo 选择

- [ ] 已在交付说明中写明采用 `editorial-light`、`immersive-dark` 或 `mobile-inspiration`。
- [ ] 明亮与暗色桌面版保留主画布、模式选择、候选结果和参数区四层信息结构。
- [ ] 移动版保留拼贴灵感板、已选素材状态、底部创作输入和单一主操作。
- [ ] 没有只通过替换主题颜色来冒充另一个 Demo。

## 状态与响应式

- [ ] 空白、生成中、成功、失败状态均可理解且可恢复。
- [ ] 生成中阻止重复提交，但保留用户已输入的意图。
- [ ] 小屏隐藏或折叠右侧参数栏，不出现横向挤压。
- [ ] 卡片没有用图片文字替代真实文案和控件。

## 视觉

- [ ] 主画布优先级高于参数栏和导航。
- [ ] 分割线、留白与卡片圆角使用主题 Token。
- [ ] 结果卡统一比例、标题基线和元信息位置。
- [ ] 双强调色只用于模式、主按钮与少量状态提示，不泛滥。
