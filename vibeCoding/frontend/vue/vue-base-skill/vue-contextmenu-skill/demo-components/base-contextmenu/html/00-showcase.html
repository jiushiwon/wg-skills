vue-contextmenu-skill · 8 形态 + 4 联动
菜单项渲染统一收敛到 base-list-item，4 槽位（icon / label / shortcut / divider）
实际场景：树节点 / 表格行 / 桌面图标 / 文件浏览器 / 通用任意区域
形态 01 · 基础菜单（右键空白区） trigger=contextmenu
右键此区域 → 弹出基础菜单
形态 02 · 嵌套子菜单（hover 展开多级） option.children
右键此区域 → 含「视图 / 编辑」二级子菜单
形态 03 · 图标 + 快捷键菜单（编辑器式） option.icon + option.shortcut
右键此区域 → 复制 / 粘贴 / 撤销 / 重做
形态 04 · 分割线 + 危险项（删除置底，红色高亮） option.divider + option.danger
右键此区域 → 重命名 / 复制 / 移动 / 删除（红色）
形态 05 · 动态条件菜单（按角色切换菜单项） option.show
当前角色：管理员
右键此区域 → 菜单项随角色变化
形态 06 · 左键点击触发（按钮下拉） trigger=click
左键点击此区域 → 弹出菜单（与右键触发共存）
形态 07 · 键盘导航（↑↓ Enter Esc）+ 边缘检测 内置 keyboard + adjustPosition
右键此区域 → 弹出菜单后按 ↑↓ Enter Esc
提示：在右下角右键可触发边缘检测，菜单会自动左 / 上翻转
形态 08 · 7 种 variant 风格（basic / finder / win / vscode / admin / notion / nav） variant=basic/finder/win/vscode/admin/notion/nav
basic（默认）
finder（macOS）
win（资源管理器）
vscode（深色）
admin（Ant Design）
notion（极简）
nav（强引导渐变）
联动 01 · 树节点右键菜单（与 vue-tree-skill） base-tree @contextmenu → base-contextmenu
联动 02 · 表格行右键菜单（订单列表） 行 @contextmenu → base-contextmenu
联动 03 · 桌面图标右键菜单（macOS 风） 图标 @contextmenu → base-contextmenu
联动 04 · 文件浏览器右键菜单（多类型动态） 文件 / 文件夹 菜单不同
- 在任意区域点击右键 / 左键查看事件 -
