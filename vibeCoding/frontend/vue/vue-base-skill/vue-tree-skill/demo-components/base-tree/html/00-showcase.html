vue-tree-skill · 8 形态 + 右键联动
节点渲染统一收敛到 base-list-item，8 种形态通过 prop 开关叠加
实际项目：组织架构 / 文件浏览器 / 分类树 / 权限树
形态 01 · 基础树（组织架构 / 分类树） 默认 variant=basic
形态 02 · 复选框树（权限分配 / 多选） checkbox = true
形态 03 · 懒加载树（按需加载子节点） lazy + load
形态 04 · 可拖拽树（节点排序 / 跨层级拖入） draggable = true
形态 05 · 右键菜单树（与 vue-contextmenu-skill 联动） @contextmenu → base-contextmenu
提示：在任意节点上点右键 → 弹出操作菜单
形态 06 · 可搜索树（关键字过滤 + 高亮匹配） search + filterNode
形态 07 · 可编辑树（单击节点进入编辑态） editable = true
形态 08 · 节点图标树（每节点自定义 icon） TreeNode.icon
风格 09 · finder 风格文件树（variant=finder） variant=finder
风格 10 · vscode 资源管理器（深色 IDE） variant=vscode
