# vue-admin-skill

Vue 3 管理端技能，基于 Vue3 + TypeScript + Element Plus 生成标准化后台管理系统骨架。

## 状态

🚧 规划中

## 技术栈

- Vue 3 + TypeScript
- Element Plus
- Pinia
- Vue Router 4
- Vite

## 核心功能

- 布局系统（侧边栏/顶部栏/面包屑/标签页）
- 权限管理（路由守卫/按钮权限/动态菜单）
- 页面模板（登录/仪表盘/列表/详情/表单/错误页）
- 组件封装（ProTable/ProForm/ProUpload/ProEditor/ProChart）
