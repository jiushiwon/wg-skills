# 前端 UI 一致性审查器规范

> 上位规范：`../AGENTS.md`；仓库规范：`../../../AGENTS.md`。

## 定位

本 Skill 负责跨页面发现和说明一致性问题，不拥有主题 Token、公共组件或业务页面的实现权。

## 红线

1. 默认只读，报告必须区分事实、推断和待确认项。
2. 基线优先服从项目已有主题、公共组件和设计规范；不能仅用“出现次数最多”替代事实来源。
3. 低置信度组件归类、营销/沉浸式页面和业务特例不得自动修改。
4. `--apply` 前必须已有报告、明确的基线与用户确认；只允许改 CSS、Token 引用或已确认的纯视觉组件替换。
5. 不修改 props、事件、状态、接口、路由、权限、业务文案和数据结构。
6. 静态扫描不能证明视觉结果；未做截图或浏览器校验时，报告必须标注“静态证据”。

## 自检清单

- [ ] 所有引用的 references 文件存在且在 `SKILL.md` 中可定位。
- [ ] 原有 `reuse|align|hardcode|all` 参数和触发词仍被兼容。
- [ ] 报告包含组件来源、Token、状态和页面模式，不只罗列裸值。
- [ ] 报告包含页面 gutter、固定区避让、安全区/键盘证据和图标语义，不把视觉相似误判为同一实现。
- [ ] 报告中的每个建议都带证据位置、置信度和风险。
- [ ] 自动修复项均为高置信度且用户已确认。
