# 图标语义契约审查规则

图标不是装饰。相同业务动作在同一产品域内，图形、尺寸、颜色、禁用态和点击区域共同组成组件契约。

## 审查字段

| 字段 | 说明 |
|---|---|
| 动作语义 | 编辑、删除、返回、搜索、清空、更多、关闭、复制等 |
| 资产来源 | SVG 组件、图标库、静态图片、Unicode 字符、页面私有绘制 |
| 图形 | 同语义是否使用同一 glyph；若不同是否有状态/品牌理由 |
| 尺寸 | 是否走 icon size Token 或组件 size variant |
| 颜色 | default / hover / disabled / danger 是否走语义色 Token |
| 触达 | 图标本体小不等于点击区小；移动端必须检查可点击容器 |
| 可访问性 | 有操作含义时是否有 label、title、aria 或等价文案 |

## 动作一致性规则

1. “编辑”默认使用同一铅笔图形及同一默认色；黑色、浅色、主题色不能仅因页面作者习惯变化。
2. 删除、警告、不可逆动作可使用危险色，但必须由危险语义而不是视觉偏好决定。
3. 同一图标的实心/描边、图片/SVG/字符混用，若无性能或品牌原因，应标为来源漂移。
4. 图标在深色背景、禁用态、选中态可使用不同颜色；报告中需记录状态原因，不能仅比较颜色值。

## 例外

品牌 Logo、插画、内容图片、第三方平台 Logo 不进入“同动作图标”比对。营销 Hero 的装饰图标可以例外，但操作性图标仍需保留可识别的语义和点击区域。
