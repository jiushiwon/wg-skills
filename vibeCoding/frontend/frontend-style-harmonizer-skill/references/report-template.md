## 风险定义

| 风险 | 含义 |
|---|---|
| P0 | 无障碍、关键操作可用性或明显误导；优先修复 |
| P1 | 跨页面可感知的不一致，影响使用或品牌可信度 |
| P2 | 结构/Token 漂移，容易积累维护成本 |
| P3 | 可渐进治理的裸值、重复样式或命名问题 |
