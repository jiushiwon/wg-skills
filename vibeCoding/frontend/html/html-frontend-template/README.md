# html-frontend-template

> 纯 HTML + 原生 JS 管理后台模板，无任何框架依赖，面向自媒体运营平台。

## 快速上手

直接用浏览器打开 `index.html`，或用静态服务器：

```bash
python -m http.server 8080
```

后端地址在 `assets/js/api.js` 配置 `API_BASE`。

## 页面模块

热点管理、创作中心、文章库、素材库、发布中心。

## 技术特点

纯原生（零框架）、响应式、深色模式、localStorage 本地存储、可对接后端 API。

## 适用 / 不适用

- 适用：快速原型 / MVP、不想引入 Vue/React 的轻量后台
- 不适用：复杂交互的中大型后台（建议 `vue-generate-skill`）
