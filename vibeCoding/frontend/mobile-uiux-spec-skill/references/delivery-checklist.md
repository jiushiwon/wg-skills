# 移动端设计交付与真机验收清单

## 设计交付前

- [ ] 明确目标端、最小系统版本、是否支持平板/折叠/鸿蒙。
- [ ] 标明单位：pt、dp/sp、rpx、CSS px/rem/vw 或 vp/fp。
- [ ] 标明页面 gutter、卡片 padding、模块 gap 的责任层。
- [ ] 标明导航类型：原生、自绘或沉浸式；自绘导航不写死状态栏/胶囊高度。
- [ ] 固定底栏写明自身高度、安全区、内容占位和键盘策略。
- [ ] 每个输入/提交页面给出默认、输入中、键盘弹起、错误、禁用和完成状态。
- [ ] 图标给出视觉尺寸与点击命中区，不能只标图标本体。
- [ ] 图片给出比例、裁切策略、加载失败与空态。

## 开发验收时

- [ ] 最小宽度设备：无横向溢出，关键操作可见。
- [ ] 常规刘海/手势设备：顶部内容不压系统区，底栏不压 Home Indicator。
- [ ] Android 常规机：字号、行高、触控区和系统字体缩放可用。
- [ ] 小程序自绘导航：标题、右侧操作和胶囊不重叠。
- [ ] 键盘弹起/收起：输入框、提交/发送按钮、最后一项都可达。
- [ ] 固定栏：内容滚动至末项时不被挡住。
- [ ] 有鸿蒙目标：窄窗、展开态、字体放大、窗口尺寸变化均验收。
- [ ] 记录真实设备、系统版本、运行端和未覆盖项。
