# 页面 Demo 设计与迭代

- 模板 ID：`page-demo-iteration`
- 版本：`1.0.0`
- 分类：前端设计 / 页面 Demo

适用于已经有页面、静态 Demo、原型或截图，需要围绕一项用户任务改善布局、反馈或交互。整个新项目的生成、专项真机审计和设计系统重建应使用对应 Skill。

## 可复制提示词

```text
请围绕一个用户任务迭代页面 Demo。

页面或参考：{{PAGE}}
用户要完成：{{TASK}}
本轮只调整：{{SCOPE}}
目标视口或运行端：{{VIEWPORTS}}

先定位页面入口、现有组件、主题变量和数据来源。只有截图时，列出能确认的视觉事实及需要代码或运行环境才能核对的部分。

1. 用现有组件与主题变量，给出一项可验证的最小设计改动。保留原业务状态、接口、路由、权限与文案。
2. 为主路径和相关异常准备可重复的模拟数据。按任务选择加载、空态、错误、禁用或未登录状态。
3. 区分静态画廊、交互 Demo 和业务模板。标清本次交付属于哪一层，以及能验证什么。
4. 默认输出方案。只有在我明确要求修改时才应用改动，并列出涉及文件和恢复范围。
5. 按目标视口验证布局，检查内容溢出、关键动作及其反馈。涉及表单或弹窗时，检查键盘触发、焦点进入与恢复、关闭。涉及小程序安全区或软键盘时，分别记录模拟结果与真机证据。

按顺序输出：现状证据、改动方案、场景和模拟数据、验收清单、已验证结果与待验证项。每项验收写清操作和预期结果。
```

## 示例输入

| 字段 | 值 |
|---|---|
| `PAGE` | Vue CRUD 展示页 |
| `TASK` | 只用键盘打开新增弹窗、关闭并继续操作 |
| `SCOPE` | 新增触发控件、弹窗焦点和关闭操作 |
| `VIEWPORTS` | 1440px 与 390px，桌面浏览器 |

示例通过条件：Enter 或 Space 打开弹窗，焦点进入姓名字段，Esc 关闭，焦点回到新增按钮。分别记录布局和键盘结果。
