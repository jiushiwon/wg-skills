# 提示词模板

这里发布可以直接复制的任务提示词。每份模板聚焦一个明确任务，保留来源 Skill 的关键约束和验收条件。遇到跨模块实现、完整交付或复杂例外时，继续读取来源 Skill。

| 类型 | 负责什么 | 例子 |
|---|---|---|
| 项目规则 | 在一个仓库内反复适用的约束 | 项目根的 `AGENTS.md`、`CLAUDE.md` |
| Skill | 完整工作流、参考资料、示例与交付规范 | 前端一致性审查、主题、页面生成 |
| Prompt | 本轮任务的输入、边界和验收 | 页面 Demo 设计与迭代 |

## 第一份模板

[页面 Demo 设计与迭代](design/page-demo-iteration.md)适用于已有页面、截图或原型。复制文件中的提示词块，替换输入，然后提交给智能体。正文可直接使用。智能体能访问仓库时，可以按文件内的链接继续读取完整规范。

## 模板约定

- 使用稳定的模板标识和版本。修改输入或输出约定时同步版本及示例。
- 写清目标、输入、必须遵守的规则、输出结构与通过条件。缺少证据时要求标注缺口。
- 引用来源 Skill 以方便维护。上游规则有变化时同步压缩后的内容。
- 漫剧的角色一致性、分镜和连续镜头可以沿用同一结构。项目级 `AGENTS.md`、`CLAUDE.md` 模板后续单独分类，明确作用范围与加载方式。
