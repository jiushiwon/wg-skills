# vue-admin-skill

**项目级技能**：组合现有技能矩阵，一键生成完整管理后台系统。

## 核心特点

- 不使用任何第三方组件库（Element Plus / Ant Design 等）
- 全部基于 wg-skills 技能矩阵
- 前端组件来自 vue-base-skill / vue-table-skill / vue-form-skill
- 后端来自 springboot-init / fastapi-init / go-gin-init
- 数据库规范来自 database-design-skill

## 使用方式

```markdown
/vue-admin-skill 帮我生成一个后台管理系统
```

## 技能矩阵

| 层级 | 技能 | 用途 |
|------|------|------|
| 前端 | vue-base-skill | 基础组件 |
| 前端 | vue-table-skill | 表格组件 |
| 前端 | vue-form-skill | 表单组件 |
| 前端 | vue-tree-skill | 树形组件 |
| 前端 | vue-theme-skill | 主题系统 |
| 后端 | springboot-init-skill | Java 骨架 |
| 后端 | fastapi-init-skill | Python 骨架 |
| 后端 | go-gin-init-skill | Go 骨架 |
| 数据库 | database-design-skill | 设计规范 |
| 鉴权 | auth-module-skill | JWT 鉴权 |

## 生成内容

- 前端：Vue3 + 自有组件库
- 后端：按语言选择（Java/Python/Go）
- 数据库：MySQL/PostgreSQL
- 鉴权：JWT + 权限管理
- 布局：侧边栏 + 导航栏 + 面包屑
- 页面：登录、仪表盘、用户管理、角色管理、菜单管理
