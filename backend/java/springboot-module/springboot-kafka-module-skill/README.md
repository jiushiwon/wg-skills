# Java Kafka Module Skill

面向已有 Spring Boot 项目的 Kafka 快速集成技能。

## 功能

快速集成 Kafka 生产者、消费者、事务消息等能力。

## 使用方式

```
帮我加 Kafka
集成 Kafka 消息队列
```

## 能力

| 能力 | 说明 |
|------|------|
| 生产者 | 同步/异步发送消息 |
| 消费者 | 消费监听、批量消费 |
| 事务消息 | Kafka 事务 |
| 错误处理 | 消费失败处理 |
