# Java Redis Module Skill

面向已有 Spring Boot 项目的 Redis 快速集成技能。

## 功能

快速集成 Redis 缓存、分布式锁、限流、消息队列等能力。

## 使用方式

```
帮我加 Redis
集成 Redis 缓存
添加分布式锁
```

## 能力

| 能力 | 说明 |
|------|------|
| 缓存 | @Cacheable 注解缓存 |
| 分布式锁 | Redisson 分布式锁 |
| 限流 | 基于 Redis 的接口限流 |
| 消息队列 | Redis Stream |
| Session | Spring Session 共享 |
