# Java Fast Learning Skill

面向**零基础小白**的 Java 快速入门学习助手。

## 功能

通过关键词触发，快速回答 Java 核心知识点，帮助建立知识框架和快速查询能力。

## 使用方式

直接提问 Java 相关问题，包含关键词即可触发：

```
Java 数据类型有哪些？
Java 集合怎么用？
Java 异常怎么处理？
Java 线程是什么？
Java 枚举怎么用？
```

## 知识体系

| 类别 | 覆盖内容 |
|------|----------|
| 数据类型 | 基本类型、引用类型、类型转换 |
| 基础语法 | 变量、运算符、条件、循环 |
| 方法/函数 | 参数传递、方法重载、可变参数 |
| 面向对象 | 类、对象、继承、多态、接口 |
| 集合框架 | List、Set、Map 及其实现类 |
| 枚举 | 枚举定义与使用 |
| 异常 | 异常体系、try-catch、自定义异常 |
| IO | 文件读写、流操作 |
| 线程 | 线程创建、同步、线程池 |
| Lambda | Lambda 表达式、Stream API |
