# Python Fast Learning Skill

面向**零基础小白**的 Python 快速入门学习助手。

## 功能

通过关键词触发，快速回答 Python 核心知识点，帮助建立知识框架和快速查询能力。

## 使用方式

直接提问 Python 相关问题，包含关键词即可触发：

```
Python 数据类型有哪些？
Python 列表和元组有什么区别？
Python 异常怎么处理？
Python 装饰器是什么？
Python 异步怎么用？
```

## 知识体系

| 类别 | 覆盖内容 |
|------|----------|
| 数据类型 | int, float, str, bool, None, list, tuple, dict, set |
| 基础语法 | 变量、运算符、条件、循环、推导式 |
| 函数 | 参数类型、返回值、装饰器、lambda |
| 面向对象 | 类、继承、多态、封装、特殊方法 |
| 集合 | 列表、元组、字典、集合、推导式 |
| 异常 | try-except-finally、raise、自定义异常 |
| IO | 文件读写、JSON、pathlib |
| 线程/异步 | threading、multiprocessing、asyncio |
| 模块 | import、pip、包管理 |
