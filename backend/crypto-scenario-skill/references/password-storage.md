# 密码存储

## 一、为什么不能存加密后的密码

对称加密是可逆的，密钥必须在服务端才能解密。密钥在服务端 = 拖库时攻击者顺手就能拿到密钥并还原所有密码。**存哈希才是正解：服务器自己都还原不出来**，攻击者只能爆破，而 bcrypt / Argon2id 故意把爆破成本拉高几个数量级。

三条路对比：

| 存储方式 | 拖库后果 | 结论 |
|---|---|---|
| 明文 | 所有用户密码直接泄露 | 禁止 |
| 可逆加密（AES） | 拿到密钥即可全部还原 | 禁止 |
| 密码哈希（bcrypt/Argon2id） | 只能爆破，成本极高 | 正确 |

## 二、bcrypt 的盐机制

结果串长这样：

```
$2b$12$Ux6ZzDALRKIsS6O3vJ9M9keQfVDvdRvpA3Q9Xl3ZgSnoBRUvOzJ2Oq
│    │  └── 22 位随机盐 + 31 位哈希 ──┘
│    └──── cost = 12，即跑 2^12 轮
└───────── 算法标识
```

**盐就明文躺在串里**，这不是漏洞，是设计：

- **盐公开** → 防止彩虹表复用。攻击者拿到你的哈希串，仍需对每个用户单独爆破；没有盐的话，一张预计算好的表能一次撞库全部用户。
- **哈希保密** → 防反推原文。

**校验流程**（这就回答了"每次随机盐怎么匹配"）：

1. 从库里取出哈希串。
2. 解析出算法标识、cost、那 22 位盐。
3. 把**用户输入的密码 + 这个盐**重新跑一遍 bcrypt（cost 取串里记录的值）。
4. 比对结果的后 31 位与库里是否一致。

所以库里永远只存"密码 + 当时的盐"这一次运算的结果；下次用户登录时盐还是那一颗（因为是从串里解析出来的），不是重新随机。

## 三、cost 选型

`cost` 每加 1，计算量翻倍（2^n 轮）。

| cost | 相对耗时 | 适用 |
|------|----------|------|
| 10 | 1x | 低频登录的内部系统 |
| 12 | 4x | **默认推荐**，普通业务系统 |
| 13-14 | 8x-16x | 高价值账号、C 端登录高峰 |

目标：单次哈希耗时 100~300ms。定完不要频繁改——改了就等于所有存量密码失效，需在用户下次登录时用新 cost 重新哈希并覆盖（校验成功即重算升级）。

## 四、Argon2id

2015 年 Password Hashing Competition 冠军，NIST SP 800-63B 推荐。三个参数：

| 参数 | 含义 | 建议起点 |
|------|------|----------|
| `time_cost` | 迭代轮数 | 3 |
| `memory_cost` | 内存占用（KiB） | 65536（64MB） |
| `parallelism` | 线程数 | 1~4 |

**和 bcrypt 的本质差别**：bcrypt 靠"慢"防爆破，Argon2id 还能靠"吃内存"防 GPU / 挖矿机的并行爆破。

```python
from argon2 import PasswordHasher

ph = PasswordHasher(time_cost=3, memory_cost=65536, parallelism=2)
hashed = ph.hash(raw)
ph.verify(hashed, raw)
ph.check_needs_rehash(hashed)   # 参数升级后提示重算
```

**选型建议**：新项目且能接受多一个依赖 → Argon2id；已有 bcrypt 存量 → 保持 bcrypt，用 `check_needs_rehash` 渐进迁移，不要一刀切。

## 五、必须禁用的

```python
import hashlib
hashlib.md5(password).hexdigest()      # 2004 年碰撞被公开，2008 年有人伪造 PDF 证书骗过浏览器
hashlib.sha1(password).hexdigest()     # 2017 年 Google 做出真实碰撞
hashlib.sha256(password).hexdigest()   # 太快，GPU 每秒几十亿次
```

SHA-256 用于**文件校验、报文摘要**完全没问题；用于**密码存储**才是问题。判断标准：文件校验要的是"快"，密码存储要的是"慢"。

## 六、密钥与盐的区别

| | 盐（salt） | 密钥（key） |
|---|---|---|
| 作用 | 让相同密码产出不同哈希 | 决定谁有权验证 |
| 是否保密 | **公开**（存在哈希串里） | **保密** |
| 存放位置 | 数据库哈希串内 | 环境变量 / KMS |
| 泄露后果 | 攻击者仍需爆破 | 攻击者可离线验证任意密码猜测 |
